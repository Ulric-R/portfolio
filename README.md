# Portfolio Ulric Randrianiaina

Portfolio web étudiant L3 SIO (Génie Logiciel) présentant mes projets académiques et personnels.

## Contenu
- `index.html` : page principale
- `style.css` : design moderne basé sur variables CSS et layout responsive
- `script.js` : interactions (menu mobile, animations reveal, mini-jeu pierre-feuille-ciseaux, formulaire contact)

## Projets inclus
- Coopératives de transport (React, React Native, Python, PostgreSQL)
- Site de vote étudiant (PHP, MySQL, HTML/CSS, JavaScript)
- Hackathon médical – Gestion du stress (Python, React)
- Application web de gestion de parking (Java, JSP, MySQL)
- Gestion textile (Java, JSP, MySQL)
- Réservation d’hôtel (Nginx, Python, React)
- Portfolio personnel (React, CSS, GitHub Pages)
- Mini boutique e-commerce (React, Firebase, Stripe mock)
- Chatbot support (Python, front-end)
